## 2. Afisha.relax.by (афиша Беларуси)

- **Название ресурса/компании:** Afisha.relax.by — раздел «Афиша» портала Relax.by (ООО «Артокс Лаб», Беларусь)
- **Адрес:** https://afisha.relax.by/
- **Специализация:** афиша мероприятий Минска и других городов Беларуси: кино, спектакли, концерты, выставки, вечеринки, квесты и другие события; киноафиша с расписанием по кинотеатрам; фильтры и поиск
- **Дата и инструменты проверки:** 06.10.2026, Firefox 156.0 (DevTools: Сеть, Хранилище), PageSpeed Insights (Lighthouse)

### Архитектура и технологический стек

- **Тип приложения:** классический многостраничный сайт с рендерингом на сервере. Основной HTML-документ уже содержит весь контент (≈800 КБ), JavaScript нужен для слайдеров, фильтров, ленивой загрузки и карты.
- **Backend:** язык серверной части напрямую определить нельзя (заголовки `Server` и `X-Powered-By` скрыты). Косвенные признаки PHP: сессионная cookie `PHPSESSID` и заголовки основного документа `Expires: Thu, 19 Nov 1981`, `Cache-Control: no-store, no-cache, must-revalidate`, `Pragma: no-cache`, характерные для PHP-сессий. Это предположение, а не подтверждённый факт.
- **Frontend (по бандлу `all.js` ≈320 КБ):**
  - jQuery (в коде `window.jQuery`, плагины `jQuery.fn`) и jQuery UI 1.10.0 (виджеты, datepicker, подсказки поиска);
  - fancyBox 2.1.5 (модальные окна и галереи), Slick (слайдеры «Куда пойти»), Swiper (дополнительные карусели);
  - Modernizr (определение возможностей браузера — классы `flexbox`, `csstransitions`, `cssfilters` на `<html>`);
  - lozad.js v1.16.0 (ленивая загрузка изображений, подключена в HTML);
  - шаблоны jQuery.tmpl 1.0.0.
- **Современный блок:** `ui-kit/runtime.min.js` (≈71 КБ) собран на React 19.2.7 и отвечает за новый UI-компонент (баннер согласия на cookie, `cookie-consent.min.js`). Остальной сайт при этом на jQuery, то есть классическая вёрстка с постепенным внедрением новых компонентов.
- **Стили и сборка:** один общий файл `all.css` (≈162 КБ), один общий `all.js` с параметром-версией в URL (`?8ab072b7…`) для сброса кэша. Для старых браузеров подключены `ie.css` и `ie9.css`, в разметке есть блок `b-old-browser-modal`. Заголовок последнего изменения `all.css` — 5 марта 2021 года.
- **Статика и изображения:** отдельные домены `styles-static.relax.by` (CSS/JS), `static.relax.by` (иконки, шрифты) и `ms1.relax.by` (картинки афиш). Изображения масштабируются «на лету» параметрами в URL (`/thumb/w=600,h=900,q=81/…`), кэш `public, max-age=86400`. Шрифты вставлены в CSS как `data:` WOFF.
- **Карты:** тайлы карты загружаются с `by-map.artox.com` (собственный картографический сервис компании), в разметке есть блок `b-yandex-map`.
- **Протоколы и безопасность:** HTTP/2, сжатие gzip, заголовок `Strict-Transport-Security: max-age=15724800; includeSubDomains`. Других защитных заголовков (CSP, X-Frame-Options, nosniff) в ответе нет.
- **Объём страницы по HAR:** 96 запросов, ≈8,2 МБ (85 изображений ≈7,0 МБ, HTML ≈0,8 МБ, JS ≈0,4 МБ, CSS ≈0,16 МБ). Время по данным Firefox: DOMContentLoaded 2096 мс, load 2517 мс (без троттлинга, на домашнем соединении).

### Ограничения проверки

- Запросы к Google Tag Manager, Яндекс Рекламе и Diginetica не отображены в HAR или имеют статус 0: они были заблокированы защитой от отслеживания в Firefox, поэтому передаваемые данные не видны.
- Имя cookie с настройкой согласия на скриншоте обрезано, значение прочитано частично.
- PageSpeed Insights проверяет страницу из дата-центра Google, поэтому домашнее подключение пользователя в результате не участвует.
