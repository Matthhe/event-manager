# Технический аудит конкурентов — тематика «Сайт с мероприятиями»

## 1. Timepad (афиша событий)

- **Название ресурса/компании:** Timepad (ООО «Таймпад»), афиша и платформа продажи билетов/регистрации на события
- **Адрес:** https://afisha.timepad.ru (проверенная страница: https://afisha.timepad.ru/moscow/categories)
- **Специализация:** афиша мероприятий по городам; организаторы создают события и продают билеты/регистрации, посетители ищут события по категориям и фильтрам
- **Дата и инструменты проверки:** 05.10.2026, Firefox 156.0 (DevTools: Сеть, Хранилище, Инспектор), PageSpeed Insights (Lighthouse)

### Архитектура и технологический стек

- **Тип приложения:** одностраничное приложение (SPA) с рендерингом на клиенте. Основной HTML-документ ответа сервера — «оболочка» размером менее 1 КБ: `<div id="root"></div>` и `<noscript>` с текстом «This app requires JavaScript enabled». Весь контент строится в браузере.
- **Frontend:**
  - React 18.2.0 (в коде бандла `t.version="18.2.0"`);
  - MobX + mobx-react (управление состоянием);
  - axios (HTTP-клиент; через перехватчик во все запросы добавляется заголовок `X-Session-Id`);
  - маршрутизация в стиле react-router v6 (в коде есть `history`/`v5Compat`; точная версия по бандлу не определена);
  - react-helmet (метатеги: атрибут `data-react-helmet`), react-indiana-drag-scroll (классы `indiana-scroll-container`), moment, core-js;
  - сборка Webpack (`webpackChunk`), файлы с хэшем в имени: `bundle.5682d38e….js` (≈494 КБ), набор `chunk.*.js` (code splitting), `main.7ebb114c….css`.
- **Backend / API:** отдельный домен `ontp.timepad.ru`, REST API, ответы JSON вида `{"result":"ok","data":{...}}`. Использованные эндпоинты:
  - `GET /api/events?limit=24&registrationOpened=1&cityId=4400` — список событий (≈320 КБ на 24 события; всего найдено 1558);
  - `GET /api/categories` — 22 категории с числом событий;
  - `GET /api/dictionaries/event-filters` — справочник фильтров (10 городов, 4 ценовых диапазона);
  - `GET /api/banners` — рекламные места; `GET /api/seo/categories/region?cityId=4400` — SEO-тексты.
  Язык серверной части по заголовкам определить нельзя (заголовок `X-Powered-By` отсутствует).
- **Хостинг/CDN и протоколы:** Cloudflare (`server: cloudflare`, `cf-ray`, `cf-cache-status`), HTTP/2, сжатие Brotli/gzip. Включён Cloudflare Rocket Loader (тип скриптов подменён на вид `…-text/javascript`). Статика кэшируется (`max-age=86400`), ответы API — `no-store`.
- **Изображения:** Uploadcare-CDN `ucare.timepad.ru` с параметрами обработки в URL (`/-/crop/…/-/resize/…`). Постеры категорий — PNG по 90–190 КБ.
- **Безопасность (заголовки):** HSTS (`max-age=31536000; includeSubDomains`), `X-Frame-Options: SAMEORIGIN`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`; CSP ограничивается только `frame-ancestors`.
- **Общий сайт:** футер и форма обратной связи подгружаются скриптами с основного домена `timepad.ru` (`footer.0926462b.js` ≈626 КБ, `feedback_modal.….js` ≈241 КБ) — афиша встроена в единую экосистему сайта.
- **Объём страницы по HAR:** 67 запросов, ≈5,1 МБ (изображения ≈3,1 МБ, JS ≈1,46 МБ, JSON ≈0,33 МБ, шрифты ≈0,2 МБ, CSS ≈41 КБ). Время по данным Firefox: DOMContentLoaded 201 мс, load 337 мс (без троттлинга, на домашнем соединении).

### Div-вёрстка и семантические классы

Классы смысловые, в стиле БЭМ, с префиксами: `c` — компоненты, `l` — раскладка (layout). Хэшей в именах нет. Примеры:

- `.ctop-headerbar`, `.cbottom-headerbar`, `.cmini-headerbar` — три варианта шапки (верхняя панель, основная, мини-шапка);
- `.cbtn.cbtn--variant_primary` / `.cbtn--variant_secondary` / `.cbtn--variant_transparent` — модификаторы кнопки;
- `.ccategory`, `.ccategory__poster--large`, `.ccategory__title`, `.ccategory__count` — карточка категории;
- `.cfooter`, `.cfooter__container`, `.cfooter__content` — подвал;
- `.lpage`, `.lflex.lflex--y-axis` — контейнер страницы и flex-раскладка;
- `.ccookie-consent--open` — баннер согласия на cookie.

### Адаптивность (media-запросы)

В `main.css` (≈10 тыс. вхождений `@media`, 21 уникальное условие) используются следующие брейкпоинты:

| Условие | Назначение (по условию) |
|---|---|
| `max-width: 735.6px` | мобильные устройства |
| `min-width: 735.6px` и `max-width: 1023.6px` | планшеты |
| `min-width: 1024px` (а также `max-width: 1023.6px`) | граница «десктоп / не десктоп» |
| `min-width: 1024px` и `max-width: 1248px` | малые десктопы |
| `min-width: 1248px` | широкие экраны |
| `max-width: 640px` | узкие мобильные (единичные правила) |
| `(hover: hover) and (pointer: fine)` | hover-эффекты только для мыши |
| `(hover: none) and (pointer: coarse)`, `(pointer: coarse)` | сенсорные устройства |

Дополнительно компоненты получают модификатор `--media-point-2` (например `ctop-headerbar--media-point-2`), то есть часть логики переключения раскладки выполняется JavaScript. В `<meta name="viewport">` задано `maximum-scale=1`, что запрещает масштабирование и даёт замечание Lighthouse по доступности. Темы `prefers-color-scheme` в CSS нет (тёмная тема используется только для иконки сайта).

### Использование локального хранилища и cookies

**Cookies:**

| Имя | Домен | Срок | Secure | HttpOnly | SameSite | Назначение |
|---|---|---|---|---|---|---|
| `enPop_sessionId` | `.timepad.ru` | 1 год (до 05.10.2027) | да | нет | None | идентификатор сессии платформы enKod (попапы и push-уведомления) |
| `TPSESSID` | `.timepad.ru` | 14 дней (`Max-Age=1209600`) | да | да | Lax | сессия пользователя, выдаётся API `ontp.timepad.ru` в заголовке `Set-Cookie` |

На скриншоте вкладки «Куки» виден только `enPop_sessionId`; `TPSESSID` присутствует в HAR (в `Set-Cookie`), но во вкладке хранилища не отображался.

**Local Storage** (имена на скриншоте обрезаны, назначение определено по значениям):

- `enPop_e…` — кэш скрипта enKod (JSON с полями `expire` и `data` с кодом скрипта; подтверждено кодом загрузчика `enpop.min.js`);
- `enPop_l…` — отметка времени (ISO-дата);
- `enPop_r…` — числовой счётчик (значение `4`);
- `enPop_s…` — идентификатор сессии и пустой объект (два ключа);
- `enPop_ti…` — часовой пояс (`Europe/Moscow`);
- `enPop_v…` — версия скрипта (`v1.97.2`);
- `showState` — состояние интерфейса (пустой объект);
- `userCity` — выбранный город (`moscow`).

**Session Storage:** `sentryReplaySession` — сессия Sentry Session Replay (id, время начала и последней активности, режим `sampled: "buffer"`, то есть запись в буфер, сохраняемая при ошибке).

Корзины и пользовательских данных в хранилище нет; всё, что хранится, относится к маркетинговым и технической сервисам и к выбору города.

### Ограничения проверки

- Запросы к Яндекс.Метрике, Yandex Ads, Sentry и Cloudflare Insights в HAR имеют статус 0: они были заблокированы защитой от отслеживания в Firefox, поэтому их ответы и параметры не видны.
- HTML снят после загрузки страницы, когда баннер cookie ещё был открыт.
- PageSpeed Insights проверяет страницу из дата-центра Google, поэтому домашнее подключение пользователя в результате не участвует.
